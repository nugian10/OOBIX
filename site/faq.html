What is OOBIX?

OOBIX is a collection of 3,333 alien pet NFTs in a retro Saturday morning cartoon style — flat 2D, bold outlines, bright colors. Each alien is a different species with its own body, face and mood. The tagline is "Weird Little Universe."

Which blockchain is it on?

BNB Smart Chain Mainnet (chain ID 56). The tokens are ERC-721 NFTs. The contract is deployed at 0x607840e0a3675cf2181c98453484eb785ddd2d83 (30 Oct 2026). Nothing is minted yet — minting is not active.

How does minting work?

Minting is agent-only. There is no mint button on this site and no wallet connection here. You give a prompt to your own Binance Agentic Wallet agent, the agent calls mint() on the contract, and you approve the transaction in your own wallet. The contract only mints to wallets holding a SPACE ID .ai Agent ID.

How much does it cost to mint?

Planned pricing, from the contract draft: tokens #1–500 cost 0.0003 BNB each; tokens #501–3,333 are FREE (0 BNB). The exact price is always read from the contract by your agent before you sign — never pay an amount shown anywhere else. Nothing is live yet.

Is there a limit per wallet?

No. There is no per-wallet mint limit. The same wallet may mint again, one token per mint() call.

How is rarity decided?

By a gacha deck. All 3,333 deck slots are shuffled once before minting opens and the deck hash is committed on-chain. Mint #n opens deck slot #n, so the rarity is revealed the moment the mint confirms. Counts: Common 2,000, Uncommon 800, Rare 333, Epic 150, Legendary 50.

What do I own when I mint?

An ERC-721 NFT on BNB Smart Chain: one specific alien, with its own token ID, artwork and metadata. You can transfer it like any other ERC-721 token. Ownership is recorded on-chain, not on this website.

Where are the artwork and metadata stored?

Storage is planned on GitHub (repo nugian10/OOBIX, branch main — the repo does not exist yet, and it must be public for the raw file URLs to work). The metadata image URLs point at the GitHub raw files. No IPFS pin is planned.

Has the contract been audited?

No. There is no independent audit. The contract is a draft, it has Hardhat tests, and its source will be published for verification on BscScan after deploy — but source verification is not an audit.
